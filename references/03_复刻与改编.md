# 复刻与改编

## B 剧本还原（学习用）

目的：把原片一字不差地还原成可读的剧本，用来学习台词节奏和结构。

格式：

```text
场 1　日　外　树影街道

（00:00–00:02）
角色A（试探，冷淡）：“……”

（00:02–00:04）
角色B（平静）：“……”
△ B 不看 A，手指捏紧包带。

（00:04–00:06）
……
```

规则：

- 台词逐句写，不并句、不概括、不润色；口语重复和语气词照录。
- 每句带时间码、说话人、语气；动作行用 △ 开头，只写看得见的动作。
- 原片字幕和原声不一致时，以原声为准，并在旁边注明字幕写法。
- 听不清的标【听不清】，看不清的标【看不清】。
- 片头的固定标题、画面文字单独列出，不混进台词。

## C 改编（要发布的作品）

### 先拆出机制

把原片分成两层：

| 层 | 例子 | 改编时 |
|---|---|---|
| 机制 | 冲突怎么来、反转怎么翻、笑点靠什么 | **保留** |
| 表层 | 人名、职业、道具、台词、场景、梗 | **全部换掉** |

### 换皮四步

1. **定机制公式**（见 `02` 第一节），写在稿子最前面。
2. **换人物关系**：用用户给的角色（例如把"母子"改成"姐弟"），年龄、称呼、动机跟着调，让关系成立。
3. **换事件和道具**：同样的功能，换成新的东西。例如"总想等准备好，结果被别人先拿走"这个立意，可以从"预留的西瓜"换成"一直没买的旧吉他"。
4. **重写台词**：保留每句台词在结构里的作用（试探 / 施压 / 反击 / 揭示），句子全部重写。

### 学哪一层，听用户的

- "只学文案"：只学台词节奏和结构，不学构图、语气、口头禅。
- "只学镜头"：只学景别、调度、剪辑，故事换成用户自己的。
- "复刻剧情改成 X 和 Y"：剧情顺序和反转保留，人物全部替换，台词按新人物重写语气。

### 常见改编需求

- **竖屏改横屏**：重新设计站位，把原来上下叠的信息改成左右展开；三人戏尽量同框，不是把竖屏画面裁一下。
- **延长时长**：在机制允许的地方加一轮"升级"（第二次误会、第二个证据），不要靠拖慢节奏凑时长。
- **压缩时长**：先砍"交代"，再砍"喘口气"，最后才动"反应"；钩子和反转不能砍。
- **换风格**（漫画改真人、喜剧改韩剧质感）：剧情和台词不动，改表演、空间、光影和视效落地方式。
- **植入品牌**：放在第一个事件之后，让产品在剧情动作里出现，口播和画面要同时满足品牌方的硬性要求。

## E 爆款模板

用户想"以后都能用"时，把拆解结果抽成模板：

```markdown
## 模板名：……
- 机制公式：……
- 适合题材：……
- 节拍表（按秒）：0–3 钩子 / 3–15 立冲突 / …… / 结尾留钩
- 必备元素：一个出现三次的物件、一句前后呼应的台词……
- 禁忌：……
- 示例：用全新人物套一遍，写出 30 秒版本
```

## 不要做的事

- 把原片的人名、台词、独特设定原样搬进要发布的作品。
- 只换名字不换事件，就叫"改编"。
- 没看完原片就开始改。
