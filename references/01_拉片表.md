# 拉片表怎么填

`timeline.md` 里时间、时长、自动台词、响度已经填好。下面这些带【】的列，要看联系表和原片后逐镜填写。

## 列的含义

| 列 | 写什么 | 词汇 |
|---|---|---|
| 景别/机位/运镜 | 画面多大、从哪拍、镜头怎么动 | 景别：大远景 / 远景 / 全景 / 中景 / 中近景 / 近景 / 特写 / 大特写<br>机位：平视 / 俯拍 / 仰拍 / 过肩 / 主观 / 侧面 / 背面 / 顶拍<br>运镜：固定 / 推 / 拉 / 摇 / 移 / 跟 / 环绕 / 升降 / 手持 / 变焦 |
| 画面与表演 | 谁在画面里、在哪个位置、做了什么，表情怎么变 | 动作写成"起势 → 过程 → 收势"；写反应的起因（听到哪句话后才变脸） |
| 光影/色彩 | 主光从哪来，亮暗对比，冷暖 | 顺光 / 侧光 / 逆光 / 顶光；高调 / 低调；轮廓光；画内光源（台灯、屏幕、霓虹） |
| 声音/配乐 | 这一镜听到什么 | 对白 / 画外音 / 内心独白 / 环境声 / 音效 / 配乐（进、换、掐、无） |
| 这一刀的作用 | 为什么切在这里，这个镜头负责什么 | 交代 / 推进 / 反应 / 强调 / 揭示 / 埋伏笔 / 转场 / 喘口气 |

## 填表规则

- **一镜一行。** 自动切点不准时，先合并或拆分，再填。镜号改了就整体重排。
- **台词列要校对。** 自动转写是草稿，改成正确的字，加上说话人：`女主（压着火）：“……”`。
- **说清楚谁拿到了特写。** 一场戏里谁的近景最多，观众就站在谁那边。
- **"作用"列一定要填。** 拉片的价值就在这一列：说不出这一刀的作用，就说明还没看懂。
- **看不清就写【看不清】，** 不要猜。
